# Screenshots

Every image in this folder is generated by [`tools/screenshots`](../../tools/screenshots/README.md). The tool drives
the real add-on UI in Chrome with a **fake demo vault**, so no real pairing code, device or person appears in any of
them.

> [!WARNING]
> Never replace an image by hand with a shot of your own vault. These images are public, and a real Matter,
> HomeKit or Z-Wave setup code is a live pairing secret.

## Regenerate

```sh
cd tools/screenshots
npm install
python3 -m venv .venv && .venv/bin/pip install -r ../../anti_matter/app/requirements.txt numpy
node capture.mjs                  # everything, about 2 minutes
node capture.mjs --only readme    # just this folder's README set
node capture.mjs --only legacy    # just the wiki set in en/ and nl/
node capture.mjs --list           # every shot and group (readme, legacy, brand, gif)
```

The tool also needs Google Chrome and `ffmpeg`. It starts its own back end on a free port with temporary storage.
Home Assistant and the Matter DCL are mocked, so a run needs neither Home Assistant nor the internet. See the
[tool's README](../../tools/screenshots/README.md) for every option.

## Wiki set (`en/`, `nl/`)

The [wiki](https://github.com/Cl3tus/Anti-Matter-HA/wiki) pages *Screenshots* and *NL-Screenshots* embed these 24
files by name, through raw URLs such as:

```text
https://raw.githubusercontent.com/Cl3tus/Anti-Matter-HA/main/docs/screenshots/en/grid-view-en.png
https://raw.githubusercontent.com/Cl3tus/Anti-Matter-HA/main/docs/screenshots/nl/grid-view-nl.png
```

The names must therefore stay **exactly** as they are, and so must the `.gitkeep` files. Most names end in `-en` or
`-nl`. The full-window shots use an underscore and a historical EN/NL mismatch (`full_screen_black_en.png` versus
`full_screen_dark_nl.png`). The NL shots show the Dutch UI with a Dutch copy of the demo vault.

| EN file | NL file | What it shows |

operating system's region setting of the machine that ran the capture, not the page language.
